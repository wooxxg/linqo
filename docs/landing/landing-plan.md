# LINQO 랜딩페이지 개편 계획

작성일: 2026-11-05 · 상태: 히어로 프로토타입 검토 중

이 문서는 랜딩페이지 개편에서 지금까지 조사하고 결정한 내용을 정리한 것이에요. 섹션별 카피 전문은 [landing-copy-ko.md](./landing-copy-ko.md)에 있어요.

## 1. 목표와 범위

- linqo.ai 랜딩페이지를 새로 만든다.
- 한글 버전을 먼저 만들고, 이후 영어 버전을 만든다.
- 흐름: 링코가 무엇을 하는지 짧게 → 차별점 → 상세 기능.

## 2. 조사 결과

### 현재 랜딩 (linqo.ai)

- 구조: 히어로 → 대상 4종(학생, 교육자, 비즈니스 팀, 컨퍼런스) → 제품 화면 → 기능 6개 → 요금제 → 마지막 CTA.
- 고칠 점:
  - 히어로 헤드라인("That makes ✨ Every Moment Count")이 무엇을 하는지 말하지 않음
  - 근거 없는 수치: 99% 정확도, 10배, "1,000 teams"
  - 언어 수 불일치: 50+와 60이 섞여 있음
  - 내비게이션의 "AI 자기소개서 생성기"·"이력서 템플릿" 링크가 제품과 무관
  - 소셜 프루프, FAQ, 보안·개인정보 안내가 없음
  - 띄어쓰기 오타 ("slip away.Join")
- 현재 코드: `src/app/page.tsx`, `src/lib/i18n/home-messages.ts` (ko/en 구조 있음)

### 경쟁사 티로 (tiro.ooo)

- 포지션: "가장 정확한 AI 회의록". 국내 시장 중심, 고객사 로고 300+, ISO 27001·SOC 2.
- 링코가 차별점으로 생각했던 기능이 티로에도 이미 있음:
  - **맥락 입력:** 파일 첨부, 요약·번역에 반영. 단어장(인명·제품명)은 팀 플랜 기능.
  - **MCP 서버:** `mcp.tiro.ooo`, 읽기 전용 (노트·전사·위키 조회).
- 실시간 번역: 15개 언어, 회의 언어 1개 → 기록 언어 1개 설정 방식.
- 컨퍼런스 모드와 QR 공유가 있음.

### 결론

티로는 국내, 링코는 베트남 등 해외 시장이라 기능이 겹쳐도 괜찮다. 티로 랜딩을 구조 레퍼런스로 삼는다. 해외 방문자는 티로를 모르므로, 비교 톤은 Otter, Fireflies, Zoom 자막 같은 일반 AI 회의 도구를 기준으로 한다.

## 3. 결정 사항

| 항목 | 결정 |
|---|---|
| 타깃 순서 | ① 베트남 현지 기업·대학 → ② 글로벌 사용자 → ③ 베트남 진출 한국 기업. 한국에서도 홍보 |
| 차별점 | ① 맥락 주입 (이름·고유명사·전문용어) ② MCP (ChatGPT·Claude에서 회의 기록 재사용) |
| 다국어 기록 | 차별점이 아니라 "무엇을 하나요" 섹션과 히어로 데모의 대표 장면으로 사용 |
| 히어로 헤드라인 | 회의 전에 알려 주면, 회의 내내 정확해요 |
| 2번 섹션 제목 | 언어는 달라도, 회의는 하나로 |
| 마지막 CTA | 다음 회의, 이름 하나 틀리지 않게 |
| 미확인 기능 표기 | 일단 다 넣고, 안 되면 `[coming soon]`으로 표시 |
| 맥락 주입 예시 | 직접 만든 가상 예시 사용 (Nguyễn Thu Hà, Minh An Logistics, SKU-24B 등) |
| 테마 | 다크 모드, 배경은 거의 검정 |
| 서체 | 산세리프, 한글은 Pretendard |
| 브랜드 색 | 보라색. 정확한 hex 미확정, 임시로 `#996AFF` (앱 아이콘에서 찾은 값) |

### 다국어 처리 방식 (팀 확인)

| 구분 | 실제 동작 | 랜딩 표현 |
|---|---|---|
| 전사 | 언어 자동 감지, 섞여 말해도 각 언어로 기록 | 어떤 언어로 말해도 알아서 받아 적어요 |
| 실시간 번역 | 지정한 언어 1개로 번역 (다:1) | 모두의 말을 하나의 언어로 실시간 번역 |
| 추가 언어 번역 | Gemini 사용, 1~2초 지연 | 다른 언어도 동시에, 1~2초 안에 |

"참석자마다 각자 언어로 완전 실시간"처럼 실제와 다른 표현은 쓰지 않는다.

## 5. 디자인 레퍼런스

[Inspo](https://inspomcp.dev) 아카이브에서 "다크 모드, 산세리프, 보라색" 조건으로 찾음. 레퍼런스 페이지: https://claude.ai/artifact/1MZ72aM6AT9f4KwuH3TBMu

| 레퍼런스 | 링코에서 쓸 곳 | 가져올 것 | 피할 것 |
|---|---|---|---|
| [Linear](https://linear.app) | 전체 톤, MCP 섹션 | 거의 검정 배경, 제품 화면 중심, 앱 위에 뜬 에이전트 패널 | 너무 흐린 본문 회색 (한글 가독성) |
| [Obsidian](https://obsidian.md) | 히어로 | 다크 + 보라 버튼 하나 + 큰 앱 화면 | 휴대폰 목업까지 겹친 복잡한 화면 |
| [Uizard](https://uizard.io) | 맥락 주입 데모 | 입력창 + 보라 버튼 | 화면 아래를 덮은 보라 빛 |
| [Temporal](https://temporal.io) | 다국어 자막 | 패널 아래 언어 탭 (VI · EN · KO) | 우주 배경, 형광 연두 |
| [Astro](https://astro.build) | 신뢰 로고 줄 | 흰 단색 로고 줄 | 배경 전체 보라 그라데이션 |

원칙: 보라색은 버튼, 강조 단어, 맥락으로 바로잡힌 단어에만 쓴다. 배경 전체에 보라 그라데이션을 깔지 않는다.

처음에 고른 라이트·세리프 레퍼런스(Granola, Cartesia 등)는 다크·산세리프로 방향이 바뀌어 폐기했다.

## 6. 히어로 모션

프로토타입: https://claude.ai/artifact/2KG6BLp5nZqCYLD3FsCKng

히어로를 화면에 고정하고, 스크롤에 맞춰 장면이 넘어간다. 스크롤을 멈추면 가장 가까운 장면에 맞춰 멈춘다.

| 단계 | 장면 | 전달하는 것 |
|---|---|---|
| 처음 | 헤드라인 + 버튼 + 보라색 음성 파형, "녹음 중" 표시 | 실시간 녹음 |
| 01 다국어 기록 | 파형이 접히고 VI · KO · EN 말풍선 3개 등장 | 여러 언어로 말해도 OK |
| 02 실시간 번역 | 말풍선이 뒤집히며 한국어 번역으로 | 하나의 언어로 번역 |
| 03 맥락 주입 | 맥락 칩이 떨어지면 틀린 단어(`뉴앤투하`, `민앤 로지스틱스`)가 흔들리다 맞는 단어(`Thu Hà`, `Minh An Logistics`)로 바뀌며 보라색으로 빛남 | **차별점** |
| 04 정리 | 기울어진 앱 화면이 올라와 평평해짐 (전사 + AI 요약 + 할 일) | 제품으로 연결 |

구현 메모:
- GSAP ScrollTrigger 3.12.5: 고정(pin), 스크롤 연동(scrub), 장면 단위 멈춤(snap)
- 스크롤 길이: 데스크톱 화면 높이의 약 4.2배, 모바일 약 3배
- 모바일: 단계 표시와 요약 패널 숨김
- 모션 줄이기 설정을 켠 사용자: 애니메이션 없이 최종 앱 화면을 바로 보여 줌
- 아직 실제 브라우저에서 움직임을 확인하지 않았다 (문법 검사만 통과)
