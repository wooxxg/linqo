# LINQO 랜딩페이지 한글 카피 v1

작성일: 2026-11-05 · 상태: 초안 (카피 확정 전)

## 방향

- **타깃 우선순위:** ① 베트남 현지 기업·대학 → ② 글로벌 사용자 → ③ 베트남 진출 한국 기업. 한국에서도 홍보함.
- **레퍼런스:** 티로(tiro.ooo)의 랜딩 구조. 티로는 국내 시장, 링코는 해외 시장이라 기능이 겹쳐도 괜찮음.
- **비교 대상:** 해외 방문자는 티로를 모르므로 Otter, Fireflies, Zoom 자막 같은 일반 AI 회의 도구와 비교하는 톤으로 씀.
- **흐름:** 무엇을 하는지 짧게 → 차별점(맥락 주입, MCP) → 상세 기능.
- **버전:** 한글 먼저, 이후 영어 버전.

## 1. 히어로

- **아이브로:** 실시간 AI 통역 노트
- **헤드라인:** 회의 전에 알려 주면, 회의 내내 정확해요
- **서브:** 베트남어, 영어, 한국어가 섞여도 링코가 알아서 받아 적고 원하는 언어로 실시간 번역해요. 참석자 이름과 전문용어를 미리 넣으면 처음 듣는 단어도 정확하게요.
- **CTA:** 무료로 시작하기 (카드 등록 없이 30분 체험) / 보조: 데모 보기
- **화면:** 3명이 각자 다른 언어로 말하는 회의. 맥락으로 넣은 단어(Thu Hà, SKU-24B, Minh An Logistics)를 강조 표시.

```
🇻🇳 Thu Hà   Chúng tôi cần gửi mẫu SKU-24B trước ngày 18.
             → 18일 전에 SKU-24B 샘플을 보내야 해요.
🇰🇷 김도윤   하이퐁 선적은 Minh An Logistics가 맡기로 했죠?
             → (원문 그대로)
🇺🇸 David    Yes, and the customs docs are ready.
             → 네, 통관 서류도 준비됐어요.
번역 언어: 한국어 ▾  (+ 베트남어, 영어 추가 가능)
```

헤드라인 대안 (보관용):
- 이름도, 전문용어도 알아듣는 실시간 통역
- 언어는 달라도, 회의는 하나로 → 2번 섹션 제목으로 사용
- 우리 회의의 맥락을 아는 AI 통역사 ("통역사"가 음성 통역을 기대하게 해서 보류)

## 2. 무엇을 하나요

**언어는 달라도, 회의는 하나로**

1. **알아서 받아 적어요:** 누가 어떤 언어로 말하든 자동으로 감지해서 기록해요.
2. **하나의 언어로 번역해요:** 모두의 말을 내가 정한 언어로 실시간 번역해요. 필요하면 다른 언어도 동시에, 1~2초 안에 보여 줘요.
3. **끝나면 정리돼요:** 요약과 할 일이 자동으로 남아요.

## 3. 차별점 1: 맥락 주입

- **아이브로:** 맥락 주입
- **헤드라인:** AI가 모르는 이름, 미리 알려 주세요
- **서브:** 일반 AI 회의록은 처음 듣는 사람 이름과 회사명, 업계 용어를 엉뚱하게 받아 적어요. 링코는 세션 전에 자료나 메모를 넣으면 그 맥락을 기억하고 기록과 번역에 반영해요.

**인터랙티브 비교:** 토글(맥락 없이 / 맥락 넣고) + 탭 3개. 예시는 모두 가상 인물·가상 회사.

### 탭 ① 비즈니스 회의 (베트남 현지 기업)

넣은 맥락: `Nguyễn Thu Hà (구매팀장)`, `Minh An Logistics`, `하이퐁 항`, `SKU-24B`

| | 전사 | 번역 |
|---|---|---|
| 맥락 없이 | Let's ask **new and two ha** to send **S.K.U. twenty-four bee** samples to **Min Anne Logistics** before the **high fong** shipment. | **뉴앤투하**에게 **민앤 물류**로 샘플을 보내 달라고 하죠… |
| 맥락 넣고 | Let's ask **Thu Hà** to send **SKU-24B** samples to **Minh An Logistics** before the **Hải Phòng** shipment. | **투하** 팀장님께 **하이퐁** 선적 전에 **SKU-24B** 샘플을 **Minh An Logistics**로 보내 달라고 요청하죠. |

`[확인 필요: 실시간 번역에도 맥락이 반영되는지]` 반영되지 않으면 번역 열을 빼고 전사만 비교.

### 탭 ② 대학 강의

넣은 맥락: 강의 슬라이드 PDF (`Transformer`, `RLHF`, `Prof. Trần Minh Quân`)

| | 전사 |
|---|---|
| 맥락 없이 | Today **professor tran min kwan** explains how **our L H F** improves the **trans former**… |
| 맥락 넣고 | Today **Prof. Trần Minh Quân** explains how **RLHF** improves the **Transformer**… |

### 탭 ③ 한국 기업 × 베트남 현지 회의

넣은 맥락: `박닌 공장`, `김도윤 법인장`, `MES 시스템`

| | 전사 |
|---|---|
| 맥락 없이 | **박님 공장** **엠이에스** 도입 일정은 **김도연** 범인장님이… |
| 맥락 넣고 | **박닌 공장** **MES** 도입 일정은 **김도윤 법인장**님이… |

### 보조 포인트

- **파일 하나면 충분해요:** 발표 자료나 안건, 참석자 명단을 올리면 이름과 용어를 알아서 찾아요.
- **직접 적어도 돼요:** 발표자 이름, 회사·제품명, 전문 용어를 메모로 바로 입력할 수 있어요.
- **번역까지 정확해져요:** 맥락은 받아 적기뿐 아니라 번역에도 반영돼요. `[확인 필요]`

## 4. 차별점 2: MCP

- **아이브로:** ChatGPT · Claude 연결
- **헤드라인:** 회의가 끝나도, 내용은 계속 일해요
- **서브:** 링코를 ChatGPT나 Claude에 연결하면 지난 회의 기록을 AI가 직접 찾아 읽어요. 복사해서 붙여 넣을 필요가 없어요.
- **화면:** ChatGPT 대화창 목업

```
👤 지난주 Minh An Logistics 회의에서 정한 선적 일정이랑 담당자만 정리해 줘
🤖 (Linqo에서 회의 2건 검색)
   11월 18일 하이퐁 선적, 샘플 발송은 Thu Hà 팀장 담당으로 결정됐어요.
   근거: 10월 29일 회의 14:32…
```

- **예시 프롬프트 칩:**
  - 이번 달 강의 내용으로 시험 예상 문제 10개 만들어 줘
  - 고객사 미팅 3건에서 나온 요청사항을 표로 묶어 줘
  - 어제 회의 내용으로 베트남어 후속 메일 써 줘
- **신뢰 문구:** 읽기 권한만 줘요. 내가 승인한 앱만 회의 제목, 교정된 전사문, 요약을 읽을 수 있고, 언제든 연결을 끊을 수 있어요.
- **지원:** ChatGPT · Claude · Cursor 등 MCP를 지원하는 AI
